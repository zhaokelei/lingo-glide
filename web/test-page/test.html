Local Translation Test Page

A page for verifying triple-space input translation, selection translation and full-page translation.

Local translation keeps your text on your own machine, which matters when the document is confidential.

The model runs on the CPU, so throughput is limited and long batches must be avoided.

This paragraph is short on purpose, because the test needs to finish in a reasonable time.

Paragraph boundaries must be preserved exactly, otherwise the bilingual layout will look wrong.

Selection translation only sends a request after the user clicks the small floating icon.

Batching strategy

A batch holds at most six paragraphs and eight hundred characters, joined by a blank line.

The server answers with a stream, and each chunk is appended to the previous one.

  • Serial requests protect the machine from queueing.
  • A retry happens once when the paragraph count does not match.
