页面提示

开启后，进入英文页面约 1.5 秒自动展开一次右上角卡片；关闭后任何页面都不再自动弹出。中文、日文、韩文、法德西俄等页面无论开关如何都不会自动弹，只能手动点悬浮球；同一域名同一会话只提示一次。

方向判定

开启后三空格与划词翻译也使用上面选择的源语言，而不是自动检测；关闭时保持自动判定（避免在输入框里写英文却被当成英文页反向翻译）。

输入框

开启后每次输入框翻译都会在控制台输出 [trf-fill] 时间线（写入返回值、80/300/800/1500ms 回读、站点输入事件），并写入 data-trf-timeline 属性；排障完建议关闭。

在任意网页的输入框写完内容后，快速连按三次空格即可翻译并替换原文。密码框与搜索框会被跳过。

快捷键翻译

默认 Ctrl/Cmd + Shift + Enter；与三空格是两个独立开关，两者都可触发输入框翻译。
当前快捷键 Ctrl + Shift + Enter Ctrl 与 Cmd 均可

点击「修改快捷键」后按下组合键（至少含 Ctrl/Cmd、Alt 或 Shift），按 Esc 取消。保存后当前页面立即生效，无需刷新。

划词翻译

选中 ≤2000 字，松开鼠标后选区末端浮出「译」图标。气泡常驻，只有气泡内「关闭」按钮或 Esc 会收起。

整页翻译

触发方式：悬浮球、右键菜单「翻译此页 / 还原原文」、工具栏面板，或快捷键 Alt+T（可在 扩展快捷键页 修改）。再次触发即还原原文。

翻译缓存

命中缓存的段落不再请求模型

排除

所有设置会自动保存到 chrome.storage.sync

本地服务未启动？双击桌面上的 启动翻译模型.command，等终端出现 server listening 后刷新页面。

本扩展只访问 127.0.0.1 上的服务，不会上传任何内容到外网。
