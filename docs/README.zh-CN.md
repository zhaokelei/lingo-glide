# 本地翻译扩展（中文说明）

[English README](../README.md)

浏览器里直接翻译：输入框、划词、整页。译文由本机 llama.cpp 起服务生成，不经过任何云端，不需要账号和密钥。

要求 Chrome / Edge 111 及以上。开发与实测环境是 macOS + Edge 155 + Hy-MT2-1.8B Q4_K_M（纯 CPU）。

## 三个入口

- **输入框**：在输入框里连按三次空格（800ms 内），或按 `Ctrl+Shift+Enter`（Mac 上是 `⌘⇧Enter`）。普通 `textarea` 和富文本编辑器（Lexical / Slate / Draft.js）都能写回。快捷键可以在设置页改成自己的组合。
- **划词**：选中文字后点旁边的小图标，结果在气泡里显示，可复制。
- **整页**：右上角悬浮球，或 `Alt+T`。默认双语对照，也可以只显示译文。

站点拒绝程序写入时，不会丢掉译文：右下角弹出卡片，译文已复制，可直接粘贴。

## 安装

1. 准备模型：把 `Hy-MT2-1.8B-Q4_K_M.gguf` 放到模型目录的 `models/` 下（权重不在本仓库，见根目录 README 的 Models 一节）。
2. 启动服务：把 `scripts/run.sh` 和两个 `.command` 放到同一个模型目录，双击「启动翻译模型.command」，或直接 `./run.sh 1.8b 8080`。
3. 加载扩展：`chrome://extensions` → 打开开发者模式 → 「加载已解压的扩展程序」→ 选 `extension/`（或解压 `dist/translate-ext.zip`）。
4. 可选：打开 `web/translate.html`，这是不装扩展也能用的独立翻译页。

详细步骤、目录约定和排错见 [SETUP.zh-CN.md](SETUP.zh-CN.md)。

## 设置

设置页里可以改：

| 项目 | 默认值 | 说明 |
| --- | --- | --- |
| 服务地址 | `http://127.0.0.1:8080/v1` | 只有本地地址，扩展不访问其它网络 |
| 模型名 | `hy-mt2` | 要和服务的 `--alias` 一致 |
| 输入框快捷键 | `Ctrl+Shift+Enter` | 必须带修饰键，录制后立即生效 |
| 目标语言 | 简体中文 | 输入框和整页共用 |
| 整页模式 | 双语对照 | 或仅译文 |
| 忽略域名 | 空 | 按 hostname 匹配，命中后该站不弹提示、不显示悬浮球 |
| 缓存 | TTL 30 天 | 存本地，可在设置页查看条数、清空 |

## 已知限制

- 真实 Facebook / Messenger 的登录态没有实测。富文本回填是在官方 Lexical 0.42 测试页上验证的，站点的内部 state 同步和发送行为按观察到的特征模拟。
- 只能加载解压版扩展，没有商店版本，也不会自动更新。
- CPU 推理：单句约 1 秒，整页 40 段要几十秒。中止按钮只停后续请求，当前请求会跑完。
- 长文本按 800 字符、6 段切分，跨段的代词可能不一致。
- 整页只处理文本节点，图片、canvas、iframe 里的文字不翻。
- 缓存只有文本，没有上下文；同一句在不同页面命中同一译文。

## 开发与测试

扩展没有构建步骤，`extension/` 就是运行时源码，改完在扩展页点刷新即可。

自动化测试需要三样东西同时在线：翻译服务（8080）、测试页静态服务（8099）、开了 `--remote-debugging-port=9222` 并加载扩展的 Edge。然后跑 `python3 tests/v5b_test.py`。报告落在 `test-results/`（不进 git）。

改提示词、加语言、换模型的做法，以及每个坑的来龙去脉，都写在 [HANDOVER.zh-CN.md](HANDOVER.zh-CN.md)。
